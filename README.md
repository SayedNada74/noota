# 📓 نوتة رقمية (Noota) — منصة إدارة الديون والشكك للمحلات (Micro-SaaS)

> **الدفتر السحابي الآمن لإدارة ديون الزبائن والتحصيل الذكي عبر الواتساب**  
> مصمم خصيصاً لأصحاب السوبر ماركت، الصيدليات، الأكشاك، والورش الحرفية في مصر والعالم العربي.

---

## 🌟 القيمة الحقيقية للمشروع (Value Proposition)
1. **وداعاً لضياع الدفاتر الورقية وأخطاء الحساب:** كل مليم مسجل بدقة ومحدث آلياً في دفتر أستاذ ذري (Atomic Ledger).
2. **التحصيل بالواتساب بدون إحراج:** زر ديناميكي يفتح محادثة الزبون مباشرة بنص تذكير مهذب ومحترم جاهز بالمبلغ المطلوب.
3. **تقفيل اليومية ومطابقة الكاش:** ملخص فوري بنهاية كل يوم يوضح كاش الدرج المحصل ومبيعات الآجل، مع إمكانية مشاركة التقرير للشريك عبر الواتساب.
4. **تحديد الحد الائتماني للعميل (Credit Limit):** تنبيهات فورية صفراء وحمراء عند اقتراب أو تجاوز العميل لسقف المديونية المسموح به.
5. **طباعة البون والإيصالات الحرارية (80mm/A4):** تجهيز كشف حساب العميل للطباعة بضغطة زر مع خلفية بيضاء ونصوص سوداء حادة لتوفير حبر الطابعات.
6. **تصدير كشف الديون إلى Excel:** تنزيل كافة الزبائن ومبالغهم كملف CSV متوافق 100% مع قراءة الحروف العربية.

---

## 🛠️ البنية التقنية (Tech Stack)

* **الواجهة الأمامية (Frontend):** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Cairo Arabic Font.
* **الخادم الخلفي (Backend):** Node.js, Express.js, TypeScript, REST API, JWT Authentication.
* **قاعدة البيانات (Database):** PostgreSQL على سحابة **Supabase** عبر **Prisma ORM** مع دعم الـ Connection Pooling والـ Direct URL.
* **عزل البيانات الصارم (Multi-Tenancy):** كل استعلام مرتبط بـ `storeId` من الـ Token لمنع أي تسريب بين المحلات.

---

## 🔒 منظومة الأمان وبوابة الإدارة المشفرة (Security System)

1. **إخفاء الإدارة عن العامة:** لا يوجد أي رابط أو ذكر لمالك المنصة في الواجهة العامة للعملاء.
2. **فخ مسار `/admin`:** أي محاولة لفتح الرابط `http://localhost:3000/admin` ترجع خطأ **404 Not Found** صريح.
3. **البوابة السرية (The Vault Gate):**
   * **الرابط السري:** `http://localhost:3000/vault-gate`
   * **المفتاح السري الرئيسي (Master Key):** `noota-gate-master-2026`
   * **الدخول المباشر بالمفتاح:**  
     `http://localhost:3000/vault-gate?key=noota-gate-master-2026`

## 🚀 تشغيل المشروع محلياً (Local Development)

### 1. تشغيل السيرفر الخلفي (Backend)
```bash
cd backend
npm install
npm run dev
# السيرفر سيعمل على: http://localhost:5000
```

### 2. تشغيل الواجهة الأمامية (Frontend)
```bash
cd frontend
npm install
npm run dev
# التطبيق سيعمل على: http://localhost:3000
```

---

## 📦 خطة النشر التجاري السحابي (Production Deployment)

1. **قاعدة البيانات:** جاهزة وتعمل على **Supabase** السحابية.
2. **الـ Backend:** يمكن رفعه مجاناً أو بـ 5$ شهرياً على **Render** أو **Railway**.
3. **الـ Frontend:** رفعه بضغطة زر على **Vercel** مع ربط الدومين الخاص بك (مثل: `noota.app` أو `noota.me`).
